# MockForge Studio brand assets

MockForge Studio is an open-source form prototyping studio licensed under MIT. Use the full product name in documentation and release copy.

The logo joins angular strokes into a compact mark representing a form specification and agreement. Its petrol, emerald and mint colors match the application shell. The wordmark uses native text for clear rendering and accessibility.
